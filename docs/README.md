# `docs/`

The `@w6w/ui` user guide, published at [docs.w6w.io](https://docs.w6w.io) under **UI**.
`manifest.json` is the publish allow-list: a file in this folder that isn't listed there is not
public. See [CONTRIBUTING.md](https://github.com/w6w-io/docs/blob/main/CONTRIBUTING.md) in the docs
repo for the full convention, and this repo's [CONTRIBUTING.md](../CONTRIBUTING.md#docs) for the
rules that apply here.

| File | Route | What it covers |
| --- | --- | --- |
| `overview.md` | `/ui/overview/` | Install, stylesheet, provider, first component, entrypoints, bundler notes |
| `theming.md` | `/ui/theming/` | Light/dark resolution, the color and code tokens, restyling a component |
| `design-system.md` | `/ui/design-system/` | Spacing, type, weight, line-height and font tokens; Sass breakpoints |
| `components/index.md` | `/ui/components/` | Every component by group, and the exported types |
| `components/<group>.md` | `/ui/components/<group>/` | One page per group: `providers`, `buttons`, `data-display`, `forms`, `editors`, `flow-editor`, `modals`, `status`, `executions`, `server-resources` |
